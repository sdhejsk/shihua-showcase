# 专题进展推进会汇报 PPT 提纲

## 1. 汇报背景

- 四月份组织专题进展推进会，需总结阶段进展、下步计划、存在问题和需协调事项。
- 本次准备聚焦：近期工作遗漏检查、MapGIS 展示验证、测井数据样例、基础数据表设计、进展 PPT。

## 2. 阶段进展

- 已梳理会议准备任务清单。
- 已准备测井样例数据，字段包括井号、井名、盆地、区块、经纬度、深度、GR、RT、RHOB、NPHI、AC、CAL、SP、岩性、层位、解释结果。
- 已设计盆地/一级构造/二级构造基础数据表，包含 50 个字段，可支撑 MapGIS 图层属性表和后端业务库。
- 已完成本地展示原型，支持样例井位示意、测井曲线展示、基础表卡片展示。
- 已准备 Spring Boot 后端接口骨架，后续可替换为真实数据库和 MapGIS 服务。
- 已扩展系统模块蓝图，补充数据治理风险、接口目录、图层目录和工程化路线图。

## 3. 系统展示内容

- 首页展示任务准备状态：测井井数、曲线点数、基础表字段数、构造样例数。
- MapGIS 示意区展示盆地和井位关系，后续接入真实 MapGIS 图层服务。
- 测井曲线区展示 GR、RT、RHOB 等曲线随深度变化。
- 表格区展示测井样例数据。
- 基础构造表区展示盆地、一级构造、二级构造、目的层、储层岩性、资源潜力、需协调事项。
- 系统扩展区展示数据接入中心、空间图层服务、测井分析看板、构造基础库、会议汇报工作台和后端接口服务。
- 数据治理区展示真实数据、专家模板、MapGIS 环境和会议材料的风险状态及下一步动作。
- 接口与图层目录区展示后端 REST API 边界和后续 GeoServer/MapGIS 图层接入路径。

## 4. 可从原浙大 PPT 复用内容

- 研究背景与意义。
- 技术路线和总体架构。
- 数据治理或地质资料管理方法。
- 已有阶段性成果图件。
- 下一步研究计划和预期成果。

## 5. 存在问题

- 韩专家基础数据表模板未实际获取，当前字段为自拟样例，需专家确认。
- 真实测井数据暂未提供，当前使用公开口径样例数据结构进行演示。
- MapGIS 环境、授权、服务地址和图层规范尚未明确。
- 前后端目前为展示原型，尚未连接真实数据库、身份权限和生产环境。

## 6. 需协调事项

- 协调获取真实测井数据或可脱敏样例数据。
- 协调确认基础表字段模板、字段口径和命名规范。
- 协调 MapGIS 安装环境、服务发布方式和图层坐标系。
- 协调会议展示边界：哪些内容作为样例展示，哪些内容承诺后续完成。

## 7. 下一步计划

- 替换真实井位、测井曲线和构造边界数据。
- 在 MapGIS 中建立基础图层与属性表映射。
- 用 Spring Boot 接入结构化数据接口。
- 用 Vue 工程化改造前端展示页面。
- 形成会议版 PPT，并补入原浙大 PPT 中成熟内容。
- 引入数据库、权限、审计和数据质量流程，逐步升级为可试运行系统。
