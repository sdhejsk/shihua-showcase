终端应用层（T 层），如图 1-2 所示。

设备组织起来，虚拟化成一个个逻辑资源池，对上层提供虚拟化服务。各类空间与非空间数
据，包括卫星影像数据、矢量地图数据、三维模型数据、增值服务数据等，以及其他网络数

1.3 端 GIS 二次开发 SDK-MapGIS Client for JavaScript
MapGIS Client for JavaScript 是一款基于 MapGIS 云平台并整合了 LeafLet、
MapBoxGL、Openlayers、Cesium 四套主流开源地图框架的开发产品，用户可根据自己的
业务需求自行选择地图框架， 同时利用开源热门可视化技术，集成 Echarts、MapV、D3 等，
实现炫酷的显示效果，并集成大数据主流技术，完美融合 GIS 与大数据应用。
其中，面向二维 WebGIS 开发，MapGIS Client for JavaScript 主要推出 JavaScript for
Leaflet/MapBox/OpenLayers5（不推荐使用 OpenLayers3/OpenLayers2）三套框架，每套
框架提供全面的二次开发配套资源，以及完备的服务支持。
针对 WebGIS 应用开发，MapGIS 提供两套开发思路：


方式一：基于 MapGIS IGServer 提供的服务资源，使用 MapGIS Client for
JavaScript 二次开发库的核心库，采用传统的开发方式（如：JavaScript）构建
您的应用系统；



方式二：以传统的开发方式为基础，遵循统一的开发标准规范，将应用开发拆分
为“开发框架+功能插件”方式，并通过桥梁（标准的 JSON 配置文件）进行动
态衔接，即“纵生”式开发方式。

本手册主要介绍传统开发方式（JavaScript for Leaflet）开发入门。

1.

开发者如何使用

进行 WebGIS 应用开发，一般均采用前端开发库+GIS 服务的模式，开发者须完成如下
两个步骤：
第一步：确定 GIS 服务资源，在 MapGIS IGServer 的服务管理器中发布所需的地图服
务，以及扩展的功能服务等；
在访问 MapGIS IGServer .NET 的服务时，需要确定 GIS 服务器 IP 地址与服务端口
号，默认的 IP 地址与端口号 port 为 127.0.0.1:6163。在二次开发时，根据所使用的 MapGIS
IGServer 平台版本以及其服务管理器中 IGServer 配置情况（ip、port），对二次开发接口
中涉及的地图服务访问的 ip、port 进行相应设置。


.NET 版 IGServer 服务访问默认基地址（ip:port）：127.0.0.1:6163；



Java 版 IGServer 服务访问默认基地址（ip: port）：127.0.0.1:8089。

第二步：获取前端开发库（即 MapGIS Client for JavaScript 的 Leaflet 开发库），
拷贝到项目中，然后在代码中直接引用 include-leaflet-local.js 即可，其核心库（webclientleaflet-plugin.min.js）等将自动引入。
核心库 webclient-leaflet-plugin.min.js 基于 Leaflet 原生库扩展，
接入 MapGIS IGServer
数据与功能服务，为开发者提供简便易用的 API，功能丰富，扩展性强。目前此核心库分别
提供压缩版（webclient-leaflet-plugin.min.js）与开发版（webclient-leaflet-plugin.js）两个版
本，min 版一般在应用开发完成后发布部署阶段使用；二次开发阶段通常使用开发版，方便
查阅与调试。
